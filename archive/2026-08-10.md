## 7. [LadybirdBrowser/ladybird](https://github.com/LadybirdBrowser/ladybird)(C++) ⭐65,239 (+106)

> 웹 표준 기반의 독자적인 렌더링 엔진을 사용하는 완전히 독립적인 웹 브라우저

**무엇인가**

Ladybird는 처음부터 독립적으로 개발된 웹 브라우저로, 자체 웹 렌더링 엔진(LibWeb)과 JavaScript 엔진(LibJS)을 기반으로 구축되었습니다. 멀티프로세스 아키텍처를 채택하여 메인 UI 프로세스, 탭별 WebContent 렌더러 프로세스, ImageDecoder 프로세스, RequestServer 프로세스로 구성됩니다. 이미지 디코딩과 네트워크 연결을 별도 프로세스에서 처리하여 악성 콘텐츠로부터의 보호를 강화하고, 각 탭의 렌더러 프로세스는 샌드박스 처리되어 시스템 격리를 제공합니다. WebAssembly, TLS/암호화, HTTP/1.1, 2D 그래픽, 오디오/비디오 재생, 유니코드 지원 등 현대적 웹 표준 기능들을 포함합니다. 현재 pre-alpha 상태이며 Linux, macOS, Windows(WSL2) 및 다양한 Unix 계열 OS를 지원합니다.

**어디에 쓰나**

웹 표준에 기반한 완전히 독립적인 브라우저 환경을 필요로 하는 개발자 및 기술 커뮤니티. 기존 Chromium/Firefox 기반이 아닌 대안적 웹 엔진을 연구하거나 검증하려는 개발자. 멀티프로세스 아키텍처와 샌드박싱 기술을 학습하려는 시스템 소프트웨어 개발자. 오픈소스 브라우저 엔진의 독립적 개발에 기여하고자 하는 커뮤니티 참여자.

**살펴볼 점**

README에서 명시하듯이 현재 pre-alpha 상태로, 개발자용도만 권장되며 일반 사용자의 일상적 사용에는 적합하지 않습니다. 많은 핵심 라이브러리 컴포넌트가 SerenityOS에서 상속되었으므로, 해당 프로젝트 생태계의 의존성을 확인할 필요가 있습니다.
