### 🎯 활용 사례

- AI 에이전트 개발자 — 대규모 언어 모델이 웹 인터페이스와 상호작용하도록 자동화 작업 제어
- 웹 애플리케이션 테스트 — 복잡한 사용자 상호작용 시나리오를 명령줄로 자동 실행
- MCP 클라이언트 — agent-browser mcp 서버를 통해 표준화된 인터페이스로 브라우저 자동화 통합
