### 🔎 핵심

ECC는 AI 에이전트가 체계적으로 소프트웨어를 개발하도록 돕는 통합 시스템이다. 68개의 특화된 서브에이전트, 286개의 재사용 가능한 워크플로우(스킬), 언어별 코딩 규칙, 그리고 세션 자동 저장·학습 같은 런타임 훅을 제공해, 단순한 프롬프트 모음을 넘어 실제 엔지니어링 프로세스를 구현한다. 코드 작성 전 계획 수립, TDD 기반 구현, 독립적인 리뷰 컨텍스트, 세션 간 맥락 유지 같은 베스트 프랙티스를 인프라 수준에서 강제한다. Claude Code, Codex, Cursor, OpenCode 등 여러 에이전트 플랫폼을 지원하며, 오픈소스(MIT)로 공개되면서 GitHub App을 통한 유료 서비스(ECC Pro)도 제공한다.

### 🎯 활용 사례

- 소프트웨어 개발팀 — 테스트 주도 개발, 코드 리뷰, 보안 감사를 자동화하고 세션 간 학습을 누적하여 팀의 코딩 표준을 에이전트에 반영
- AI 코딩 에디터 사용자 — Claude Code, Cursor, Codex 같은 여러 에디터에서 일관된 에이전트 워크플로우와 규칙을 유지하며 컨텍스트 비용 최적화
- 생산 환경 배포 전 품질 보증 — AgentShield를 통한 프롬프트 인젝션 감지, MCP 서버 감사, 자동화된 검증 루프로 에이전트 생성 코드의 보안·품질 확보
