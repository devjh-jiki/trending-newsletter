> AI 에이전트팀을 위한 메모리 허브로, 대화·문서·코드를 재사용 가능한 4가지 메모리 자산(Chat Memory, Skill, LLM-Wiki, Code-Graph)으로 변환하여 여러 에이전트와 프레임워크 간 공유·관리할 수 있게 해준다.

AI 에이전트들이 학습 내용과 스킬을 팀 단위로 저장하고 재사용하도록 설계된 메모리 관리 시스템이다. 대화 이력, 구축한 스킬, LLM용 위키, 코드 그래프 등을 구조화하여 저장하고 여러 에이전트 간에 공유할 수 있다. 특히 엔터프라이즈 환경에서 AI 에이전트의 일관성과 효율성을 높이려는 조직에 유용하다.

**⚡ 바로 써보기**

```bash
git clone https://github.com/TencentCloud/TencentDB-Agent-Memory.git
cd TencentDB-Agent-Memory
npm install
npm start
```
