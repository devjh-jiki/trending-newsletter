Orca는 Claude Code, Codex, OpenCode 등 다양한 CLI 기반 AI 에이전트를 하나의 인터페이스에서 동시에 실행할 수 있게 해줍니다. 각 에이전트는 독립적인 git 워크트리에서 작동하므로 같은 프롬프트에 대해 여러 에이전트의 결과를 비교하고 가장 좋은 것을 선택할 수 있습니다. 데스크톱 앱(macOS/Windows/Linux)과 모바일 동반 앱, SSH를 통한 원격 실행을 지원하며, 터미널, 코드 편집기, 내장 브라우저와 GitHub·Linear 통합으로 완전한 개발 워크플로우를 제공합니다.

### 🎯 활용 사례

- 소프트웨어 엔지니어 — 복잡한 코딩 작업을 여러 AI 에이전트에게 동시에 맡기고 결과를 비교하여 최고 품질의 코드 선택
- 풀스택 개발자 — GitHub PR·이슈와 Linear 작업을 앱에서 직접 확인하고 각 작업별 전용 워크트리를 생성해 신속하게 개발
- 원격 개발 환경 — SSH로 고성능 원격 서버에 에이전트를 배포하여 대규모 프로젝트를 로컬 리소스 부담 없이 처리
