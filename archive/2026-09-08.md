> 복잡한 작업을 장시간에 걸쳐 자동으로 수행하는 AI 에이전트 플랫폼으로, 샌드박스, 메모리, 스킬, 서브 에이전트를 통합하여 리서치, 코딩, 콘텐츠 생성 등을 처리한다.

### 🔎 핵심

DeerFlow는 LangGraph 기반의 슈퍼 에이전트 시스템으로, 단일 AI가 아닌 다중 서브 에이전트를 조율하여 수 분에서 수 시간 걸리는 복잡한 작업을 완료할 수 있도록 설계되었다. 격리된 샌드박스 환경에서 파일 시스템, 셸 명령, 브라우저 자동화에 접근하며, 장기 메모리(DeerMem, OpenViking, mem0, Honcho 지원)로 사용자 맥락을 유지한다. 웹 검색, 이미지/비디오 생성, 리포트 작성, 슬라이드 생성 등 확장 가능한 스킬 시스템을 통해 거의 모든 작업에 적응할 수 있다. 로컬 개발부터 프로덕션 다중 워커 배포까지 Docker, Kubernetes(E2B), 로컬 실행을 지원한다.

### 🎯 활용 사례

- 데이터 분석가 — 업로드된 CSV/PDF를 자동 분석하여 인사이트 추출 및 리포트 생성
- 소프트웨어 개발팀 — 저장소 분석, 코드 리뷰, 테스트 작성, 버그 수정을 에이전트가 자동 실행하고 결과 종합
- 콘텐츠 제작자 — 주제 리서치, 아웃라인 작성, 슬라이드/웹페이지 생성, 이미지 생성을 순차 처리
- 엔터프라이즈 자동화 — Slack/Telegram 같은 메신저에서 태스크 지시, 에이전트가 백그라운드에서 실행 후 결과 회신
