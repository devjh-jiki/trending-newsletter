### 🔎 핵심

C 표준 라이브러리의 printf와 C++의 iostreams를 대체하는 포매팅 라이브러리다. Python 스타일의 형식 문법을 지원하며, C++20 std::format과 C++23 std::print를 구현한다. Dragonbox 알고리즘으로 부동소수점을 고속 처리하고, 컴파일 타임 형식 문자열 검증으로 타입 안정성을 보장한다. printf 대비 약 50% 빠르고 코드 크기는 printf 수준으로 작다.

### 🎯 활용 사례

- 시스템 소프트웨어 개발자 — 로깅, 디버그 출력, 파일 쓰기 등에서 안전하고 고속인 포매팅 필요
- 게임/그래픽 엔진 개발팀 — 대량의 실시간 데이터 포매팅 시 성능 최적화 필요
- 데이터베이스/분석 시스템 팀 — ClickHouse, MongoDB 등 대규모 프로젝트에서 포매팅 라이브러리로 채택
