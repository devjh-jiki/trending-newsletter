### 🔎 핵심

Ruflo는 Claude Code 위에 구축된 에이전트 조율 프레임워크로, 100개 이상의 특화된 에이전트를 스웜 토폴로지로 조직화하고, HNSW 벡터 데이터베이스 기반의 적응형 메모리(AgentDB)로 세션 간 학습을 유지하며, 다양한 LLM 제공자를 지원한다. MCP 서버로 등록되어 도구 호출이 자동으로 라우팅되고, 33개의 Claude Code 플러그인과 21개의 npm 플러그인으로 코드 품질, 보안 감시, 문서 생성, 아키텍처 결정 추적, IoT 관리 등 다양한 도메인을 다룬다. 에이전트 페더레이션을 통해 mTLS와 PII 감지 파이프라인으로 보호된 채널에서 신뢰 경계를 넘어 에이전트 간 협업을 가능하게 한다.

### 🎯 활용 사례

- 소프트웨어 개발팀 — 코드 리뷰, 테스트 자동 생성, 보안 감사, 아키텍처 결정 기록을 위해 전문화된 에이전트들을 협력시켜 개발 워크플로우 자동화
- 멀티팀 협업 환경 — 서로 다른 조직의 에이전트가 고객 데이터를 노출하지 않으면서 신뢰 기반의 작업 교환(예: 사기 신호 분석)을 수행
- 자율 시스템 운영 — GOAP 플래너로 자연어 목표를 실행 가능한 에이전트 계획으로 변환하고, 백그라운드 워커들이 지속적으로 코드 품질 감시 및 최적화
- 엔터프라이즈 AI 감시 — MetaHarness로 에이전트 설정의 보안 위험을 사전 스캔하고, 에이전트 행동을 신뢰 점수로 평가하며, HIPAA/SOC2 규정 감사 로그 생성
