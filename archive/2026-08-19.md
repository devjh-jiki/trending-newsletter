oMLX는 Apple Silicon 최적화 LLM 추론 서버다. 메모리 캐시(핫 티어)와 SSD 캐시(콜드 티어)로 구성된 이중 계층 KV 캐시 시스템을 통해 대용량 모델을 실행 중에도 메모리 사용을 효율적으로 관리한다. 여러 모델을 동시에 로드할 수 있으며, 연속 배칭으로 동시 요청을 처리한다. OpenAI 호환 API와 웹 대시보드를 제공하고, 네이티브 Swift 메뉴바 앱으로 서버 상태를 모니터링하고 제어할 수 있다.

### 🎯 활용 사례

- 개발자 — Claude Code 같은 AI 코딩 도구와 연동하여 로컬 Mac에서 장기 컨텍스트 대화 유지
- 연구자 — 여러 언어 모델, 비전 모델, 임베딩 모델을 한 서버에서 실행하며 메모리 제약 관리
- Mac 사용자 — 터미널이나 Apple Shortcuts에서 로컬 LLM 서버를 간편하게 시작/중지하고 메뉴바로 모니터링
