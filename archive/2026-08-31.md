Google Java Style Guide, Sun Code Conventions 등 다양한 코딩 표준을 기본으로 지원하며, XML 설정으로 커스터마이징 가능한 정적 코드 분석기다. 명령줄, ANT 태스크로 실행되며 Maven Central에서 제공된다. 예를 들어 switch문의 fall-through 같은 스타일 위반을 감지하고 에러 메시지로 보고한다.

### 🎯 활용 사례

- 개발팀 — CI/CD 파이프라인에 통합하여 코드 리뷰 전 스타일 위반을 자동 검사
- Java 프로젝트 관리자 — 팀 전체가 동일한 코딩 표준을 준수하도록 강제
- 오픈소스 유지보수자 — 기여 코드의 일관된 품질 유지
